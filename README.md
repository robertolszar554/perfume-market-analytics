# perfume-market-analytics
Automated E2E data pipeline using Selenium and Pandas to scrape, clean, and structure 5000+ perfume records from Fragrantica for advanced ML and BI analysis.

A comprehensive data engineering and analytics project focused on the perfume market. 
The pipeline automates data extraction, performs feature engineering, and prepares data 
for Machine Learning models and Business Intelligence dashboards.

## Tech Stack & Workflow
* **Extraction:** Python, Selenium (handling Cloudflare, dynamic JS loading)
* **Processing & ETL:** Pandas, NumPy, Nested JSON parsing
* **Analytics & ML:** Scikit-Learn (Random Forest Regressor for Unisex scent gender analysis)
* **Business Intelligence:** MS Excel (Power Query, Power Pivot, DAX Dashboard) - WORK IN PROGRESS
